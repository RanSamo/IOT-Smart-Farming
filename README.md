🌱 **IOT-Smart Farming**
IOT-Smart Farming is a smart agriculture platform that uses IoT sensors, AI forecasting, 
and modern web technologies to monitor crop conditions in real time and optimize farm management.

🌟 **Features**
📡 Live Sensor Monitoring – temperature, humidity, and soil moisture
📊 Data Visualization – clean, interactive charts and dashboards
🚨 Smart Alerts – real-time notifications on abnormal conditions
🔐 Secure Login – JWT auth & bcrypt encryption; farm-specific user access
☁️ AI Forecasting – weather analysis using Meta’s LLaMA model on Groq
📱 Responsive Interface – React-based, optimized for all devices


⚙️ **Tech Stack**
Frontend: React, HTML, CSS
Backend: Node.js, Express.js
Database: MongoDB
Authentication: JWT, bcrypt
AI: Groq + Meta’s LLaMA

🚀 **Getting Started**
Prerequisites:
* Node.js (includes npm)

# Clone the repository
git clone https://github.com/your-username/iot-smart-farming.git
cd iot-smart-farming

# Install dependencies
npm install

# Start both server and client
npm run dev
